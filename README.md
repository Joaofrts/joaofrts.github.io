Bem-vindo ao repositório do meu portfólio pessoal! Este site foi desenvolvido para apresentar minha trajetória profissional, acadêmica e meus principais projetos com foco em **Ciência de Dados, Engenharia de Dados e Automação (RPA)**.

## 🎯 Sobre Mim

Sou um especialista em automação e processamento de dados, apaixonado por transformar fluxos complexos em informações estruturadas. Atualmente, atuo na **Secretaria de Educação do Estado da Bahia (SEC-BA)**, onde desenvolvo pipelines de dados (ETL) e bots de extração (Web Scraping) para otimizar o monitoramento orçamentário e a tomada de decisão através de sistemas governamentais (SEI e FIPLAN).

Estudante de Análise e Desenvolvimento de Sistemas na **Universidade Católica do Salvador (UCSal)**, busco aplicar os conceitos de Ciência de Dados e Engenharia de Software para criar soluções escaláveis.
